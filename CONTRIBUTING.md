# Contributing to Principles

Thank you for your interest in contributing! Here's how to get started.

## What to Contribute

- **New principles** — Add new `.html` files for principles not yet covered
- **Improvements** — Better examples, clearer explanations, more anti-patterns
- **New languages** — Translations of existing pages
- **Corrections** — Fix technical inaccuracies or outdated advice

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a branch** for your changes (`git checkout -b add/n principle`)
4. **Make your changes** — follow the existing HTML style (dark theme, JetBrains Mono + Syne fonts, green (#00e5a0) for good patterns, red (#ff4d6d) for anti-patterns)
5. **Test** by opening the HTML file in a browser
6. **Commit** with a clear message
7. **Open a PR** against `main`

## HTML Style Guide

- Self-contained: inline CSS, inline fonts (Google Fonts), no external dependencies
- Dark theme background (`#0d1117` or similar)
- Green (`#00e5a0`) for correct/good patterns
- Red (`#ff4d6d`) for incorrect/anti-patterns
- Code blocks in monospace
- Clear heading hierarchy (H1 → H2 → H3)

## Questions?

Open an issue for discussion before making large changes.
